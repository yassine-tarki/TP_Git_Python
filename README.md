# My Study Assistant

## Introduction

This is Lab 1. It is a small Python program called My Study Assistant. It says hello to a student and asks a few questions about a study session. All the code is in one file, main.py. You run this file to start the program.

## Versions V1 to V4

I wrote main.py four times. Each time I added one thing.

In V1, the program only showed a welcome message. I made it on my computer.

In V2, the program asked for the user's first name. I sent this version to GitHub for the first time.

In V3, the subject was added on GitHub. I used git pull to get it on my computer.

In V4, the program asked for the study time. I made this change on my computer and sent it to GitHub with git push. This is the final version.

## How to run the program

You need Python and Visual Studio Code. Open the folder TP_Git_Python in Visual Studio Code. Then open the terminal (Terminal > New Terminal) and type:

```
py main.py
```

On some Windows computers, this does not work. Then type:

```
python main.py
```

The program asks for three things: your first name, the subject, and the study time in minutes.

## Git commands used

I used git init once at the start, so Git could follow my folder. After each change, I used git add to pick the file and git commit to save it with a short note. I used git push to send my work to GitHub (in V2 and V4). I used git pull to bring the changes from GitHub to my computer (in V3).
